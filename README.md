# Lumenview for Linux

Lumenview is a fast, private photo viewer by Nicholas Raymond Xerri: https://lumenview.app

This repository only holds the release files (prebuilt x86_64 and aarch64 binaries) that the Flathub package `com.nicholasxerri.Lumenview` is built from. **Install Lumenview from Flathub** (`com.nicholasxerri.Lumenview`). The tarballs here are not meant to be installed by hand.

## What it is

- Opens any folder of photos: your home folder, USB drives, SD cards and network shares. Nothing is imported or copied.
- No account, no ads, no analytics, no tracking. It goes online only for servers you add.
- Lumenview Pro is a one-time purchase, never a subscription. On Linux it's a licence key sold through Polar and entered in the app. Pro adds SMB, SFTP and WebDAV servers, archives, culling to XMP sidecars, compare, smart folders, a duplicate finder and batch tools.
