# Lumenview for Linux

Release files for the Flathub package `com.nicholasxerri.Lumenview`. Install Lumenview from Flathub; these files are not meant to be installed by hand.

Lumenview is a fast, private photo viewer by Nicholas Xerri: https://lumenview.app

- Privacy: https://lumenview.app/privacy/
- Support: https://lumenview.app/support/

Lumenview is proprietary software. The source code is not published here.
